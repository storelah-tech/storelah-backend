What changed

In the order I'd build it

Groups by job

Tools, actions on the plan, view controls and zoom each get their own cluster. No "Quick" or "Zoom" labels covering unrelated buttons.

One icon set

Matching line icons in place of mixed emoji and symbols. Fixes the shortcuts button that shows as ▬, and the two ☰ buttons.

Clear active tool

Buttons have no borders until hovered. The current tool is the only filled dark button, so the MODE: SELECT badge can go.

Plan info in the status bar

Canvas size and GFA move into a Plan settings popover. The Marked/UFA/NLA figures move next to the cursor position.

No duplicate controls

One zoom control (− 100% +). One Snap button with its step in the same dropdown. Rotate and Lock area appear only for the tool that uses them.

Simpler header

Undo/Redo and save status sit next to Publish. Save draft and Delete move into the ⋯ menu, away from the main button.
